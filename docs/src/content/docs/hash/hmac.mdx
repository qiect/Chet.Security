# HMACHelper 帮助类

## 概述

[HMACHelper](https://github.com/qiect/Chet.Security/blob/main/Chet.Security/Hash/HMAC.cs) 是一个静态帮助类，提供基于哈希消息认证码（HMAC）的计算能力，覆盖 HMAC-MD5、HMAC-SHA1、HMAC-SHA256、HMAC-SHA384、HMAC-SHA512 与 HMAC-SM3 六种变体。

非 SM3 系列使用 .NET BCL 的 `HMACMD5`/`HMACSHA1`/`HMACSHA256`/`HMACSHA384`/`HMACSHA512` 实现；HMAC-SM3 使用 BouncyCastle 的 `HMac` + `SM3Digest` 实现。

## 主要特性

- 🔐 **算法齐全** — 覆盖 HMAC-MD5/SHA1/SHA256/SHA384/SHA512/SM3 六种变体
- 🇨🇳 **国密支持** — HMAC-SM3 基于 BouncyCastle 的 `HMac` + `SM3Digest` 实现
- 📝 **多输入支持** — 接受字节数组、字符串（UTF-8 编码）输入
- 🎨 **多输出格式** — 支持小写十六进制字符串与原始字节数组两种输出
- 🔑 **密钥验证** — 通过密钥保证消息完整性与真实性
- 🌐 **多目标框架** — 同时支持 `netstandard2.1` 与 `net8.0`

## HMAC-MD5

> ⚠️ **安全提示：** HMAC-MD5 不建议用于新系统的安全场景，仅在与遗留系统兼容时使用。

### ComputeHmacMD5(byte[] data, byte[] key)

计算字节数组与密钥的 HMAC-MD5，返回小写十六进制字符串。

```csharp
public static string ComputeHmacMD5(byte[] data, byte[] key);
```

| 参数名 | 类型 | 描述 |
|--------|------|------|
| data | `byte[]` | 待计算的消息数据 |
| key | `byte[]` | HMAC 密钥 |

**返回值：** 32 字符长度的小写十六进制 MAC。

**示例：**

```csharp
using Chet.Security;

byte[] data = new byte[] { 0x68, 0x65, 0x6C, 0x6C, 0x6F };
byte[] key = new byte[] { 0x73, 0x65, 0x63, 0x72, 0x65, 0x74 }; // "secret"
string mac = HMACHelper.ComputeHmacMD5(data, key);
// mac: "..." (32 chars)
```

### ComputeHmacMD5(string text, string key)

将消息字符串与密钥字符串（均为 UTF-8 编码）计算 HMAC-MD5，返回小写十六进制字符串。

```csharp
public static string ComputeHmacMD5(string text, string key);
```

| 参数名 | 类型 | 描述 |
|--------|------|------|
| text | `string` | 待计算的消息字符串 |
| key | `string` | HMAC 密钥字符串 |

**返回值：** 32 字符长度的小写十六进制 MAC。

**示例：**

```csharp
using Chet.Security;

string mac = HMACHelper.ComputeHmacMD5("hello", "secret");
// mac: "..." (32 chars)
```

### ComputeHmacMD5Bytes(byte[] data, byte[] key)

计算字节数组与密钥的 HMAC-MD5，返回原始字节数组（16 字节）。

```csharp
public static byte[] ComputeHmacMD5Bytes(byte[] data, byte[] key);
```

| 参数名 | 类型 | 描述 |
|--------|------|------|
| data | `byte[]` | 待计算的消息数据 |
| key | `byte[]` | HMAC 密钥 |

**返回值：** 16 字节长度的原始 MAC。

**示例：**

```csharp
using Chet.Security;

byte[] mac = HMACHelper.ComputeHmacMD5Bytes("hello"u8.ToArray(), "secret"u8.ToArray());
// mac.Length == 16
```
